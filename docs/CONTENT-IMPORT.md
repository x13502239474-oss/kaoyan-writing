# 教材 / 讲义 / 范文 / 真题 导入协议

本站内置内容全部是**标注过的演示或 AI 生成示例**，不含真实真题与官方范文。
你可以把自己的资料按下面的 JSON 结构整理后导入，**只追加内容、不覆盖任何学习记录**，导入条目统一标记为「导入资料」。

## 一、最快路径

1. 「数据管理」→ **下载内容包模板**，得到 `写作内容包模板.json`；
2. 用记事本 / VS Code 打开，按你的资料填写（模板里每一类都有一条示例）；
3. 「数据管理」→ **导入内容包**（也可把文件拖到虚线框），确认数量后完成；
4. 到课程 / 素材库 / 范文 / 专项训练 / 写作考试里就能看到新内容。

只想加一两条？用「粘贴文本快速建素材」直接生成一条个人素材，或到对应页面点「新建」。

---

## 二、文件顶层结构

```json
{
  "app": "kaoyan-writing",
  "kind": "content",
  "version": 1,
  "note": "可选：这一包资料的来源说明",
  "courses": [],
  "materials": [],
  "modelEssays": [],
  "drills": [],
  "exams": []
}
```

五个数组**都是可选的**，只写你要导入的即可。系统会追加，不会清空未提到的类别。

通用规则：
- `id` 建议全局唯一；缺失会自动生成。**重复 id 会导致合并恢复时被认为是同一条**，建议用有意义的前缀，例如 `wc_2026_wangcheng_p12`。
- 所有文本字段都是纯文本，可含换行 `\n`；不要放 HTML。
- 系统会给每条导入内容自动加上 `label: "import"` 与 `importedAt`，页面上显示「导入资料」标签；`source` / `note` 字段请自行写明真实出处、页码、年份。
- 单个 JSON 建议控制在几 MB 以内（localStorage 总量通常 5–10MB）。

## 三、课程 `courses[]`

```json
{
  "id": "course_book_ch1",
  "title": "第一章 论证有效性分析概述",
  "category": "论证有效性分析",
  "summary": "本章简介（显示在列表卡片）",
  "minutes": 30,
  "tags": ["教材", "基础"],
  "source": "《XXX 写作分册》P12–P30",
  "points": [
    { "id": "ch1_p1", "title": "知识点标题", "content": "知识点说明（支持换行）" }
  ],
  "difficulties": [
    { "title": "重点难点标题", "content": "说明文字" }
  ],
  "examples": [
    { "title": "示例标题", "text": "示例 / 范文片段", "analysis": "详细解析", "label": "import" }
  ],
  "keyTakeaways": ["本讲要点一", "本讲要点二"]
}
```

详情页会自动生成：知识点折叠面板、重难点、示例与解析、要点速记、个人笔记、标记完成、加入复习计划（整讲或单个知识点）。

## 四、素材 `materials[]`

```json
{
  "id": "mat_book_001",
  "theme": "创新与守正",
  "type": "论据",
  "title": "素材标题",
  "content": "素材正文",
  "source": "《XXX》P45 / 自己整理 / 网页链接",
  "tags": ["辩证", "条件"]
}
```

`type` 常用值：`论据` / `案例` / `名言` / `示例表达` / `角度`（也可自定，会自动出现在筛选栏）。
`theme` 自定即自动成为新主题分类。
⚠️ 引用名言请写明真实出处，**不要录入虚构的名人语录**；AI 改写的句式请标成「示例表达」并在 `source` 说明。

## 五、范文 `modelEssays[]`

```json
{
  "id": "model_2023_essay_01",
  "title": "范文标题",
  "type": "论说文",
  "prompt": "题目 / 材料原文",
  "source": "出处说明（年份、书目、页码；若为本人习作请注明）",
  "structure": [
    { "part": "开头", "desc": "这一段承担的论证任务" }
  ],
  "paragraphs": [
    { "id": "pa_01", "role": "开头 · 亮论点", "text": "段落正文", "analysis": "论证思路分析" }
  ]
}
```

`type` 常用：`论说文` / `论证有效性分析`。
`paragraphs` 决定「逐段精读」的段数；`structure` 决定「结构拆解」的环节。二者可以分开写。
导入后仍可在页面上补充好句收藏与个人笔记；`learned` 进度留空即可。

## 六、专项训练 `drills[]`

```json
{
  "id": "drill_2020_real_01",
  "type": "找出逻辑漏洞",
  "title": "练习标题",
  "material": "题目材料原文",
  "prompt": "作答要求",
  "hint": "可选提示",
  "reference": "参考要点（仅用于提交后自查，不是标准答案）",
  "minWords": 150,
  "source": "《XXX 真题》2020 年"
}
```

`type` 建议沿用内置 7 类之一，这样会出现在对应分类下：
`审题训练` / `找出逻辑漏洞` / `分析论证结构` / `提炼中心论点` / `列写作提纲` / `段落写作` / `完整文章写作`。
也可以用自定义类型，会自动出现在分类筛选里。

## 七、试卷 `exams[]`

```json
{
  "id": "exam_2021_real",
  "title": "2021 年写作模拟卷",
  "type": "综合",
  "durationMin": 60,
  "description": "两题连做，按正式考试要求计时",
  "source": "出处说明",
  "questions": [
    {
      "id": "exam_2021_q1",
      "type": "论证有效性分析",
      "prompt": "写作要求",
      "material": "题目材料原文",
      "minWords": 600,
      "maxWords": 800,
      "reference": "参考思路 / 参考范文（会标注为导入资料，非标准答案）"
    },
    {
      "id": "exam_2021_q2",
      "type": "论说文",
      "prompt": "写作要求",
      "material": "题目材料原文",
      "minWords": 700,
      "maxWords": 900,
      "reference": "参考思路"
    }
  ]
}
```

- `durationMin` 用于倒计时；`minWords` / `maxWords` 只做提示，**不会阻止交卷**；
- 多题试卷会在考试页出现题目切换条，逐题自动保存草稿；
- 请以目标考试当年公布的正式时长与字数要求填写这些参数。

## 八、关于你提供的 PDF

`D:\图片\考研\写作\` 下 11 份 PDF 多为扫描图像（单份最大约 530MB），本机没有 OCR 引擎，直接提取会产生大量错字，因此**没有把识别结果硬塞进网站**。推荐做法：

1. 用任意 PDF 转文字 / OCR 工具（如支持中文 OCR 的工具）导出需要的章节；
2. **人工校对**关键段落、题目与出处；
3. 按上面结构整理成 JSON（可用 Excel 整理后导出，或让 AI 按模板批量转换）；
4. 分册分章导入，每包不要太大，导入前先「导出全量备份」；
5. 导入后在页面上抽查一两条，确认换行、标点、标签正常。

> 使用他人教材、真题与范文时请自行确认使用权限，并只在个人学习范围内使用。

---

## 九、导入后想撤销怎么办

内容包导入只做追加，没有内置「一键撤销本次导入」。处理方式：

- 导入前先「导出全量备份」（系统在执行「重置 / 清空」前也会自动下载快照）；
- 若需回退：`数据管理 → 恢复备份（覆盖）`，选择导入前的备份文件；
- 或到对应页面手动删除导入的条目（课程/素材/范文/作文都支持删除）。

系统在执行覆盖恢复前还会再自动下载一份「恢复前快照」，可层层回退。
