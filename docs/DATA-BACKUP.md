# 数据备份与恢复说明

## 一、数据存在哪里

- 位置：浏览器 `localStorage`，键名 **`ky_writing_v1`**。
- 内容：一份完整 JSON，包含课程进度、笔记、素材、收藏、范文学习进度、练习记录、考试答卷、作文与版本、复习队列、薄弱环节、活动日志、个人设置。
- 特点：**不上传云端、不需要账号、不跨设备自动同步**。
- 风险：只属于「当前浏览器的当前配置文件」。清理浏览数据、无痕窗口、换浏览器、换电脑、卸载浏览器都会导致数据不可见。

> 建议：**每周导出一次备份**，在清理浏览器缓存或重装系统前务必先导出。

---

## 二、导出备份（3 秒完成）

1. 打开网站 → 底部「我的」→「数据管理」（或右上角齿轮）；
2. 点 **「导出全量备份」**；
3. 浏览器下载 `写作备份_2026-11-07_1930.json` 之类的文件；
4. 把这个文件放到网盘 / U 盘 / 另一个目录，别只留在「下载」文件夹里。

也可用「复制备份 JSON」把内容粘到备忘录，但文件方式更稳妥。

导出文件结构：

```json
{
  "app": "kaoyan-writing",
  "kind": "backup",
  "version": 1,
  "exportedAt": "2026-11-07T11:30:00.000Z",
  "note": "考研写作自学网站 · 全量备份…",
  "data": { "...完整状态..." }
}
```

## 三、恢复备份

1. 打开网站 →「数据管理」→ 点 **「恢复备份（覆盖）」** 或 **「恢复备份（合并）」**；
2. 选择之前下载的 `.json` 文件；
3. 系统会先**校验**文件（格式、`app` 标识、必要字段），并显示文件里有多少课程/素材/作文；
4. 确认后，系统会**先自动下载一份「恢复前快照」**，再执行恢复 —— 即使选错文件也能退回来。

### 覆盖 vs 合并

| 模式 | 行为 | 适用场景 |
|---|---|---|
| **覆盖**（推荐） | 用备份文件完整替换当前数据 | 换浏览器、换电脑、误删后回滚、数据错乱 |
| **合并** | 按 `id` 追加备份里当前没有的记录，保留双方内容 | 想把另一台设备上的作文/笔记并进来 |

合并不会删除当前已有数据；若想「只保留备份内容」请用覆盖。

校验失败时会明确提示原因（JSON 格式错误 / 不是本站备份 / 缺少必要字段），**不会破坏现有数据**。

## 四、常见场景操作

| 场景 | 怎么做 |
|---|---|
| 换了浏览器 / 新电脑 | 旧浏览器导出 → 新浏览器打开网站 → 覆盖恢复 |
| 清理缓存前 | 先导出；清完再覆盖恢复 |
| 误删了作文或课程 | 若有最近备份 → 覆盖恢复；若无 → 用「恢复前快照」（系统在执行重置/清空前会自动下载） |
| 想把两台设备的记录合起来 | 分别导出 → 在其中一台用「合并恢复」导入另一份 |
| 想全部重来 | 「数据管理 → 重置为初始演示数据」或「清空全部学习数据」（两者都会先自动下载快照） |
| 数据占用过大 | 「数据管理」页可看占用；删掉不需要的历史作文/版本，再导出一次备份 |
| 提示「本地存储空间已满」 | 先导出备份，删除部分长文历史版本，再刷新页面 |

## 五、手工检查 / 高级用法

在浏览器地址栏执行 `javascript:` 不方便，可在页面按 F12 → 控制台输入：

```js
// 查看当前数据大小
JSON.stringify(localStorage.getItem('ky_writing_v1')).length

// 手动导出到控制台（复制输出另存为 .json）
copy(localStorage.getItem('ky_writing_v1'))

// 手动写入备份文本（谨慎，先备份当前数据）
// localStorage.setItem('ky_writing_v1', 粘贴的JSON字符串); location.reload();
```

> 直接改 localStorage 有风险，优先使用页面里的「导出 / 恢复」按钮，它们带校验与自动快照。

---

## 六、安全边界

- 恢复文件可以是任意来源的 JSON，导入前建议确认文件来源；系统只读取约定字段，不执行其中代码。
- 备份里包含你的全部笔记与作文原文，**请自行妥善保管，不要随意分享**。
- 本项目不联网、不上传，数据离开本机的唯一方式是你主动点「导出」。
