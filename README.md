# 考研写作 · 个人自学网站

一个**移动端优先、零依赖、零构建、数据全部保存在本机**的写作自学工作台。

> 当前已启动：**http://localhost:5183/**（服务窗口保持打开即可）

---

## 一、快速启动（三选一）

| 方式 | 操作 | 适用 |
|---|---|---|
| **① 双击启动（最省事）** | 双击项目根目录的 `start.bat` | Windows 日常使用 |
| ② 命令行 | 在 `D:\Kaoyan-Project\writing` 下执行 `npm start` | 推荐 |
| ③ 等价命令 | `node server.js` | 没有 npm 时 |

启动后终端会显示：

```
✅ 考研写作自学网站已启动
➜ 电脑访问:  http://localhost:5183/
➜ 手机访问:  http://192.168.x.x:5183/  (需同一 Wi-Fi)
```

- **不需要 `npm install`**：项目没有任何第三方依赖，`package.json` 只是提供启动命令。
- **端口自动避让**：5183 被占用时自动尝试 5184、5185…，不会与其他三个网站冲突。
- 停止服务：在窗口按 `Ctrl+C`，或直接关闭窗口。
- 环境要求：Node.js 18+（本机为 v22.22.2）。

⚠️ 请通过 `http://localhost:5183/` 打开，**不要双击 `index.html`**：浏览器会因本地文件安全策略拦截 ES 模块。

---

## 二、手机上使用

1. 电脑运行 `start.bat`，手机连**同一个 Wi-Fi**；
2. 手机浏览器打开终端里显示的 `http://192.168.x.x:5183/`；
3. iPhone：Safari → 分享 → **添加到主屏幕**；Android：Chrome → 菜单 → **安装应用 / 添加到主屏幕**。

- 在 `localhost` / `127.0.0.1` / HTTPS 下会注册 Service Worker，支持**离线打开**；
- 通过局域网 `http://` 访问时全部功能与数据保存照常可用，只是不注册离线缓存（浏览器安全策略），「添加到主屏幕」仍可使用；
- 手机端编辑区字号 17px、行高 2.05，不会触发 iOS 输入自动缩放；按钮最小 44px；
- **不同设备的数据彼此独立**（各自浏览器 localStorage），暂不跨设备同步。

## 四、技术选型与目录

原生 ES Module + 原生 CSS + 原生 DOM 事件，Node 内置 `http` 模块做静态服务。
**不用框架、不用打包器、不用数据库** —— 个人长期使用的工具最怕依赖腐化，这样十年后打开仍能跑。

## 五、数据保存机制

- 全量状态以 JSON 存在浏览器 `localStorage` 的 `ky_writing_v1` 键下；
- 结构性操作（勾选、收藏、提交、评分…）立即写入；编辑器输入**每 0.6 秒**防抖写入，并在切换页面 / 后台 / 关闭前强制 flush；
- 刷新、关闭浏览器、重开电脑（不清缓存）数据都不丢；
- 考试倒计时基于时间戳计算，暂停/刷新/关闭后能准确续考；
- 数据结构带版本号与字段容错，读入时自动补齐缺失字段，不会因手工编辑的 JSON 少字段而崩溃；
- 预留升级空间：数据层集中在 `js/store.js`，未来接云端只需替换 `save()` / `init()`，视图层无需改动。

**备份与恢复完整说明 → `docs/DATA-BACKUP.md`**（含换浏览器、清缓存、误删恢复、覆盖 vs 合并）。

**导入教材/讲义/范文/真题 → `docs/CONTENT-IMPORT.md`**（含可直接填写的 JSON 模板）。

## 六、内容声明（重要）

- 站内**不含任何真实考研真题、官方范文或权威机构课程内容**；
- 所有内置内容都带来源标签：`演示内容` / `AI 生成` / `个人添加` / `导入资料` / `古籍·公有领域`；
- 名言只收录《论语》《荀子》《孟子》等公有领域古籍原文并注明出处；其余句式明确标注为「AI 生成示例表达，非真实名人语录」；
- 题目材料、范文、试卷、参考要点均标注为演示 / AI 生成，时长与建议字数是**演示参数**，请以目标考试当年正式要求为准；
- **本站不自动评判作文**。所有分数来自你（或老师）的人工评分与自我评价；参考内容只是自查要点，不是标准答案；
- AI 批改如未来接入，应作为独立扩展功能，不是正常使用的必要条件；
- 你提供的 11 份 PDF 多为超大扫描件（最大 530MB），本机无 OCR 引擎，无法可靠抽取为可引用文本，因此未直接嵌入。请按 `docs/CONTENT-IMPORT.md` 把需要的章节整理成 JSON 后导入（可借助任意 PDF 转文字 / OCR 工具并人工校对）。

## 八、已知限制

1. 数据在**当前浏览器的当前配置文件**里；无痕模式、清理缓存、换浏览器/设备会看不到原数据 → 请定期导出 JSON 备份。
2. 无账号、无云端、无跨设备同步（按需求刻意不做）。
3. 局域网 `http://` 下浏览器不允许注册 Service Worker，因此该方式没有离线缓存；需 HTTPS 或 localhost。
4. 不内置 PDF 解析与 OCR；不内置 AI 批改；不自动判分。
5. localStorage 容量通常 5–10MB，纯文本作文足够用很久；`数据管理` 页可随时查看占用，超限会给出明确提示。
6. 版本对比为段落/行级 LCS 差异，不做字符级逐字高亮。

## 九、常见问题

**Q：关掉窗口后网站打不开了？**
A：服务窗口需保持运行。重新双击 `start.bat` 即可，数据不会丢。

**Q：换了浏览器数据没了？**
A：数据按浏览器隔离。用旧浏览器打开 → `数据管理 → 导出全量备份` → 新浏览器打开 → `恢复备份（覆盖）`。

**Q：想全部重来？**
A：`数据管理 → 重置为初始演示数据`（会自动先下载一份当前数据快照）。

**Q：能改自动保存间隔 / 考试日期 / 昵称吗？**
A：`数据管理 → 个人设置`。

**Q：怎么把真题放进去？**
A：`数据管理 → 下载内容包模板`，按模板填写 `exams` / `drills` / `modelEssays` 等数组，再「导入内容包」。只追加内容，不动学习记录。
